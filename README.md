# Mike's HUD asset gallery

[Open the gallery](https://arkigos.github.io/mikes-hud-assets/)

Twenty class art pitches for Priest, Warrior and Rogue, plus D1, a reference
sheet assembled from the installed Druid textures and IM Fell lettering.
The gallery includes full-size transparent PNG downloads, class filters,
background choices and a shortlist saved in each visitor's own browser.

These are art references and design pitches, not downloadable playable addons.
The Druid sheet rearranges existing components for comparison. The other themes
still need extraction, geometry registration and client verification before use.

The class pitches were generated with imagegen. D1 was mechanically composed
from existing textures without repainting them. Source details are linked in
the gallery. The smaller WebP thumbnails are for browsing only.

This repository contains static gallery content. GitHub Pages publishes the
root of the default branch. No build step or server is required.
